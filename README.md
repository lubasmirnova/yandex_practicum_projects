🛠 Технический стек
Языки: Python (Pandas, NumPy, Scipy, Matplotlib, Seaborn), SQL (PostgreSQL, BigQuery).

Инструменты: Tableau, Excel, Wrike, Google Analytics.

Методы: RFM-сегментация, проверка статистических гипотез, EDA, визуализация данных, маппинг бизнес-процессов.

📂 Основные проекты
1. Сегментация клиентов и анализ поведения (Python)
Задача: Разработка стратегии SMS-маркетинга для интернет-магазина.

Решение: Проведен полный цикл EDA и RFM-сегментация. С помощью теста Краскела-Уоллиса доказана статистическая значимость различий между сегментами.

Результат: Выделены 3 бизнес-кластера и сформированы сценарии коммуникаций для повышения удержания (retention).

2. SQL-исследование базы данных книжного сервиса (SQL)
Задача: Сформировать ценностное предложение для нового продукта на основе данных о поведении пользователей.

Решение: Написание сложных SQL-запросов для анализа актуальности библиотеки, популярности авторов и активности сообщества.

Результат: Выявлены ключевые драйверы роста (современный контент и ядро лояльных читателей) для маркетинговой стратегии.

3. Дашборд лояльности клиентов (NPS) в телекоме (Tableau)
Задача: Визуализация уровня лояльности пользователей по всей России.

Решение: Разработка интерактивного дашборда в Tableau с возможностью сегментации по возрасту, полу, географии и типу устройств.

Результат: Инструмент позволяет операционным командам быстро находить причины низкого NPS в конкретных сегментах.
